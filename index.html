Automated server maintenance platform

A secure pipeline for automated maintenance updates across 50+ Ansible-managed, WireGuard-connected servers, built with strict access policies and secure networking. Hosts run a lightweight Go client for mTLS-secured maintenance checks, an API gateway schedules each host's maintenance slot, custom aptly-based repository mirrors serve the packages, and dashboards give an overview of host package lists and updates.

Open source · Personal project

Minnumst: a self-hosted family history archive

A public archive, an editorial desk and an API that keeps every story revision, built end to end from the app to the hardened host it runs on. OpenTofu creates the Hetzner host, Ansible hardens it to the CIS benchmarks (scored with Lynis in CI), and Traefik with Authentik is the only way in. Releases are multi-arch images with an SBOM and build provenance.
